⚠
Versión EDU obligatoria para programar
La versión G1 STD no permite programación personalizada ni acceso al SDK. Para desarrollar aplicaciones propias es imprescindible la versión EDU. La diferencia de precio (35 k€ → 70 k€) se debe a: potencia de cómputo (hasta NVIDIA AGX Orin 64 GB / 275 TOPS), paquete de sensores, manos dexterosas articuladas y nivel de soporte técnico incluido.

02 · Mercado cuadrúpedos
No todos los robots son iguales
Existe una diferencia crítica entre los modelos de consumo y los programables de nivel profesional.
✓
Recomendación: iniciar con cuadrúpedo
Coste 3–5× menor que el humanoide, SDK y ROS 2 maduros, menor riesgo operacional. Una vez validado el caso de uso, el salto al G1 estará respaldado por datos reales.
✕
Robots de MediaMarkt (2.600 – 4.000 €) — no válidos
Control por mando únicamente. Sin SDK ni API de programación. No integrables con sistemas propios. Diseñados para entretenimiento, no para aplicaciones industriales.
